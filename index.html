Open study materials for Manipal University Jaipur, maintained by Accelerate and contributed by students. Everything here is a file in a public Git repository — no login, no ads, no upload quota, nothing that dies when somebody's Drive fills up.

Sections

  • Past Year Papers Mid-term and end-term papers, organised by year of study and branch. First → fourth year

Contributing

Adding a paper is a single JSON entry — no build tools, no account beyond GitHub. The contributing guide walks through it, and the club's Git guide covers the Git side if this is your first pull request.

About the material

Question papers are set and owned by Manipal University Jaipur. This archive indexes and mirrors them for study and revision by its own students; it claims no copyright over them. If you hold rights in something here and want it removed, open an issue or email the club and it will be taken down.

Maintained by Accelerate, the open-source club at Manipal University Jaipur.
